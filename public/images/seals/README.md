# 인감 이미지

견적서 대표자 칸에 겹쳐 찍히는 도장 파일. 목록은 `lib/neander/finance/supplier.ts`
의 `SEALS` 가 들고 있고, 견적서 문서에는 그 `id` 한 줄만 남는다.

> ⚠️ **도장 파일은 깃에 커밋하지 않는다.** 이 저장소는 public 이고, 배경이
> 투명한 고해상도 법인인감은 그대로 문서 위조에 쓸 수 있다. `.gitignore` 가
> 이 폴더의 이미지를 막아 두었다 — 각자 로컬에 내려받아 놓고 쓴다.
>
> 배포본은 이 폴더를 보지 않는다. 도장은 Firestore `neander_fin_seals` 에
> 올려 두고, `api/neander/finance/seals/{id}` 가 로그인한 재무 사용자에게만
> 내준다(보안 규칙에 없는 컬렉션이라 클라이언트가 직접 못 읽는다). 이 폴더의
> 파일은 **올리는 원본**이다:
>
> ```
> npm run finance:upload-seals            # 무엇을 올릴지 보기
> npm run finance:upload-seals -- --apply # 올리기 (바뀐 것만)
> ```
>
> Firestore 에 없으면 라우트가 이 폴더를 대신 본다 — 로컬 개발용.

여기에 놓을 파일:

| 파일명                  | supplier.ts 의 id | 도장                                  |
| ----------------------- | ----------------- | ------------------------------------- |
| `yoo-jaeyoung.png`      | `yoo-jaeyoung`    | (주)네안데르 법인인감 · 대표이사 유재영 (윗점 ●) |
| `lee-dongju.png`        | `lee-dongju`      | (주)네안데르 법인인감 · 대표이사 이동주 (윗별 ★) |
| `wajakhomes.png`        | `wajakhomes`      | 와작홈즈 상호인 · 유선화 (사각)          |

네안데르 법인인감 둘은 가운데 위 표식(점/별)만 다르고 나머지가 같다.
**다른 사람의 인감이다** — 파일을 바꿔 넣지 않도록 주의한다.

조건:

- **배경이 투명한 PNG 가 가장 안전하다.** 도장은 글자 위에 겹쳐 찍힌다.
  `mix-blend-mode: multiply` 를 걸어 두어 흰 배경 스캔본도 대체로 흰 부분이
  비쳐 보이지만, 브라우저 인쇄에서 블렌드가 무시되면 이름을 덮는다.
- 정사각형이 가장 낫다 (와작홈즈처럼 사각인은 세로가 길어도 `object-fit: contain`
  으로 칸 안에 맞춘다). 한 변 512px 이상. 화면에서는 46px 로 줄여 쓰지만 인쇄(300dpi)
  에서 테두리가 뭉개지지 않으려면 원본이 커야 한다.
- 스캔본이면 흰 바탕을 지우고 붉은 획만 남긴다.

올라가 있지 않으면 화면의 도장 자리에 「파일 없음」 이 뜨고(인쇄에는 안
나온다), 인쇄본은 도장 없이 나간다.

도장을 더 등록하려면 파일을 여기에 놓고 `supplier.ts` 의 `SEALS` 에 한 줄
추가한 뒤 `finance:upload-seals -- --apply` 로 올린다. 배열 첫 항목이 새 견적서의 기본값이다.
